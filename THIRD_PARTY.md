# Data and dependencies

Fashion-MNIST was introduced by Han Xiao, Kashif Rasul and Roland Vollgraf, *Fashion-MNIST: a Novel Image Dataset for Benchmarking Machine Learning Algorithms* (2017), arXiv:1708.07747.

- Source: https://github.com/zalandoresearch/fashion-mnist
- License: MIT, as stated in the upstream repository. The dataset files are downloaded from upstream rather than included in the source archive.
- Published checksums are used to identify the original files. SHA256 digests of the actual downloaded files are recorded in `results/seed42/dataset_manifest.json`.

PyTorch, NumPy and the testing/build dependencies retain their own licenses. This repository contains original project code and depends on their installed packages; it does not vendor their code.
